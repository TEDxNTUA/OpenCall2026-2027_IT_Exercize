# Open Call 2026-2027: Εργασία IT

## Περιγραφή
Σε αυτό το repository θα βρείτε μια απλή έκδοση της ιστοσελίδας του TEDxNTUA. Χρειάζεται αλλαγές και προσθήκες στη λογική (JavaScript) και στο design (CSS). Επιπλέον, η ιστοσελίδα περιέχει σφάλματα που πρέπει να εντοπίσετε και να διορθώσετε.

Για να δείτε τη σελίδα, ανοίξτε το αρχείο `index.html` στον browser.

## Τι πρέπει να κάνετε
Η άσκηση αποτελείται από τρία μέρη:

**1. Αντίστροφη μέτρηση (Countdown)**
Ο μετρητής πρέπει να δείχνει πόσος χρόνος απομένει μέχρι την επόμενη εκδήλωση, στις **09.05.2027**. Η μέτρηση πρέπει να ενημερώνεται σε πραγματικό χρόνο (κάθε δευτερόλεπτο), με βάση την τρέχουσα ώρα, και να εμφανίζει σωστά ημέρες, ώρες, λεπτά και δευτερόλεπτα. Σκεφτείτε επίσης τι πρέπει να συμβαίνει όταν περάσει η ημερομηνία.

**2. Ομιλητές: design και φίλτρο**
Σχεδιάστε με CSS τις καρτέλες των ομιλητών, ώστε να είναι ευανάγνωστες και ελκυστικές, και βεβαιωθείτε ότι το φίλτρο κατηγοριών λειτουργεί σωστά.

**3. Συνολικό αποτέλεσμα**
Στο τέλος, η ιστοσελίδα πρέπει να είναι ολοκληρωμένη και να λειτουργεί σωστά: να προσαρμόζεται στα κινητά, να λειτουργούν το μενού και η φόρμα επικοινωνίας και να μην εμφανίζονται σφάλματα στην κονσόλα του browser. Στο Pull Request περιγράψτε ποια προβλήματα εντοπίσατε.

## Κανόνες
- Επιτρέπονται μόνο HTML, CSS και JavaScript (χωρίς frameworks ή βιβλιοθήκες).
- Είστε ελεύθεροι να χρησιμοποιήσετε οποιεσδήποτε πηγές κατά την εκτέλεση της εργασίας, αλλά είναι πολύ σημαντικό να κατανοείτε κάθε γραμμή κώδικα. Ενδέχεται να σας ζητηθεί να εξηγήσετε τον κώδικά σας.

## Τρόπος υποβολής
1. Κάντε **fork** του repository.
2. Κάντε clone και δημιουργήστε νέο **branch** με το όνομά σας (π.χ. `onoma-eponymo`).
3. Δουλέψτε στον κώδικα και κάντε **commit** με σαφή μηνύματα.
4. Κάντε **push** στο branch σας και ανοίξτε **Pull Request** προς το αρχικό repository.
5. Στην περιγραφή του Pull Request γράψτε τι αλλάξατε και ποια σφάλματα εντοπίσατε.

Μέτρα αξιολόγησης της λύσης σας αποτελούν η σωστή **λειτουργία** της ιστοσελίδας και η **δημιουργηκότητά** σας. Πολύ σημαντικό ρόλο έχει το να μας επικοινωνήσετε τι μάθατε μέσω αυτής της διαδικασίας, καθώς δεν θεωρούμε απαραίτητο να γνωρίζετε ήδη τα παραπάνω θέματα, αλλά αναζητούμε την ικανότητα σας να χρησιμοποιήσετε εργαλεία και να τα κατανοήσετε.

Επίσης, **δεν** είναι απαραίτητη η ολοκλήρωση κάθε μέρους της εργασίας, ειδικά αν αφορά λόγους έλλειψης χρόνου.
